结论档位（每张卡第一行）：由 排雷 · 年线 · 买点距离 三件事合成，只回答「现在能不能动手」，不预测涨跌。
①排雷🔴有雷 → 「别追」（一票否决）；②分红不可持续 → 「别追」；
③年线下方 → 「观察」——只按股息率格子慢接，不按趋势加仓（不管离买点多近）；
④年线上方再看买点：已跌破买点 → 可买；离买点 10% 以内 → 观察；还差 10% 以上 → 别追（追高）。
　例外：已跌破买点、但 60 日位置已经 >80%（短期涨到区间顶部）→ 先归 观察，等回落再动手；ETF 没有财年分红、算不出买点，只标 底仓。
当日涨跌 = 现价 ÷ 上一交易日收盘；红涨绿跌。量比 = 当日成交量 ÷ 前 5 个交易日均量（收盘后口径），≥1.5 标「放量」。
位置 = 当前价在近 60 个交易日高低区间中的百分位；越低越接近区间底部。区间与均线用不复权真实成交价（网格挂单要按真实价，复权价是合成价）。
股息率 = 最近完整财年（中期+末期）每股分红 ÷ 现价，是可核的年度口径；灰标 TTM 是近 12 个月实际除权金额，一年派三次的公司（如工行）会偏高，除权日刚落在窗口外的会偏低，两者差 ≥0.5pp 才显示。
分红下降 / 分红不可持续：前者＝最近完整财年每股分红实质下滑（≥5% 且 ≥0.02 元）；后者＝分红率超过当年利润，靠留存或特别分红撑起来的股息率不能当常态。
买点 = 每股年度分红 ÷ 5.5%（你的第一笔规则，保留）；右侧正数＝现价还要再跌这么多才到买点，负数（绿）＝已跌破买点。分红不可持续的票不显示买点（撑出来的股息率不能当基准）。
股息率不是决定项：它只决定买点价位，不单独构成结论。档位优先级是 排雷 → 年线 → 买点距离：有雷先否决；年线下方只慢接不加仓；站上年线再看离买点多远。
低位共振（三条件同时成立才亮标）：①60 日位置 < 40% ②周 BOLL 处于「中下 / 下轨以下」③股息率 ≥ 4.5%。
年线 = 250 日均线：「年线上方 / 下方」为现价与年线的关系，右侧是偏离幅度（+3.2% = 高出年线 3.2%）。年线之下的票只按股息率格子慢接，不按趋势加仓。
斐波那契三档 = 近期低点 + 区间 × 0.382 / 0.5 / 0.618，可作网格挂单位。
驱动 = 利润来源：「订单驱动」利润由订单量/销量/份额决定；「价差驱动」利润由产品价差、净息差、运价决定（右侧小字为具体驱动因子）。
价差 ≠ 必剔——价差只标识利润来源，不等于要卖。真正要警惕的是商品价差（煤价/油价/运价/铝价），因为它的高股息建立在周期高位利润上。
已核实 = 代码、名称、现价、股息率经三源交叉核对（东财分红表 + 腾讯行情 + 独立复算）；未核实 = 尚未核对，不可据此决策。
排雷 = 七类实查（点徽章展开全部依据）：①商誉占净资产比 ②未来12月解禁 ③近12月减持公告 ④近12月问询/监管/处罚 ⑤股权质押比例（中登全公司股东合计，每周五更新） ⑥对外担保（近12月公告，区分「对并表子公司」与「对参股/非并表主体」） ⑦诉讼仲裁 + 股份冻结。
